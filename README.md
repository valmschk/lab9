# Project Name: FarmerProductsApp

## Description
FarmerProductsApp — это мобильное приложение для iOS, разработанное как агрегатор фермерских хозяйств и эко-лавок для быстрого заказа натуральных продуктов. Программное решение позволяет автоматически определять геолокацию пользователя, отображать ближайшие торговые точки на интерактивной карте и гибко настраивать характеристики товаров перед покупкой. Оформление заказа поддерживает различные формы оплаты (онлайн, ЕРИП, терминал или наличные) и сохранение детализированных комментариев для курьерской службы. Все учетные записи пользователей, каталоги товаров и история транзакций кэшируются локально и надежно управляются с помощью встроенной базы данных SQLite.

## Installation
Для локальной установки, сборки и запуска приложения на вашем компьютере выполните следующую последовательность шагов:

### Предусловия (Системные требования)
* Операционная система: **macOS 12.0** или новее.
* Среда разработки: **Xcode 14.0** или выше.
* Инструменты сборки: установленный менеджер пакетов **CocoaPods** (если используются внешние зависимости) и утилита **Git**.

### Пошаговое руководство
1. **Клонирование репозитория:**
   Откройте Терминал и выполните команду для клонирования проекта на ваш компьютер:
   ```bash
   git clone [https://github.com/valmschk/lab9.git](https://github.com/valmschk/lab9.git)
После завершения скачивания перейдите в папку проекта:

Bash
cd lab9
Открытие проекта в Xcode:
Запустите файл проекта в среде разработки Xcode:

Bash
open FarmerProductsApp.xcodeproj
Индексация и сборка:
Дождитесь окончания автоматической индексации файлов проекта (Indexing...). Локальный файл базы данных SQLite автоматически развернется в системной папке приложения при первой компиляции.

Выбор устройства и запуск:
В верхней панели Xcode выберите активную схему приложения и целевое устройство (симулятор iPhone 15/16). Нажмите комбинацию клавиш Cmd + R для сборки и запуска приложения.

Usage
После успешного запуска приложения на симуляторе Xcode или реальном устройстве, вы можете протестировать его функции по следующему сценарию:

Регистрация и вход: На стартовом экране пройдите регистрацию. Введенные данные запишутся в локальную базу данных SQLite, после чего выполнится автоматический вход.

Поиск эко-лавок на карте: Перейдите на вкладку "Карта". Приложение определит вашу геопозицию и автоматически подсветит маркеры ближайших фермерских хозяйств, либо позволит вам выбрать нужное хозяйство вручную.

Выбор продуктов и кастомизация: Перейдите в каталог выбранной эко-лавки. Выберите продукт (например, фермерское молоко или мед) и измените его характеристики (выберите объем 0.5л/1л или укажите сорт), после чего нажмите "Добавить в корзину".

Оформление и оплата: Откройте экран "Корзина", проверьте список товаров и введите адрес доставки. Выберите один из четырех способов оплаты: Онлайн-оплата, ЕРИП, Терминал или Наличные.

Комментарий и подтверждение: В специальном текстовом поле оставьте комментарий для курьера (например, детали доставки или бесконтактный метод). Нажмите "Подтвердить заказ". Система сохранит чек в SQLite, очистит корзину и отправка заказа перейдет в обработку.
