# Project Name: FarmerProductsApp

## Description
FarmerProductsApp — это мобильное приложение для iOS, разработанное как агрегатор фермерских хозяйств и эко-лавок для быстрого заказа натуральных продуктов. Программное решение позволяет автоматически определять геолокацию пользователя, отображать ближайшие торговые точки на интерактивной карте и гибко настраивать характеристики товаров перед покупкой. Оформление заказа поддерживает различные формы оплаты (онлайн, ЕРИП, терминал или наличные) и сохранение детализированных комментариев для курьерской службы. Все учетные записи пользователей, каталоги товаров и история транзакций кэшируются локально и надежно управляются с помощью встроенной базы данных SQLite.

Для локального запуска и тестирования приложения на вашем компьютере выполните следующие шаги:
1. Клонируйте репозиторий с исходным кодом проекта:
   ```bash
   git clone [https://github.com/](https://github.com/)<ваш_логин_github>/FarmerProductsApp.git
Откройте приложение Xcode на macOS.

Выберите пункт меню File -> Open и укажите путь к файлу проекта FarmerProductsApp.xcodeproj в клонированной папке.

Дождитесь окончания автоматической индексации файлов проекта и сборки зависимостей.

## Usage
После успешного запуска приложения на симуляторе Xcode или реальном устройстве, вы можете протестировать его функции по следующему сценарию:
1. **Регистрация и вход:** На стартовом экране пройдите регистрацию. Введенные данные запишутся в локальную базу данных SQLite, после чего выполнится автоматический вход.
2. **Поиск эко-лавок на карте:** Перейдите на вкладку "Карта". Приложение определит вашу геопозицию и автоматически подсветит маркеры ближайших фермерских хозяйств, либо позволит вам выбрать нужное хозяйство вручную.
3. **Выбор продуктов и кастомизация:** Перейдите в каталог выбранной эко-лавки. Выберите продукт (например, фермерское молоко или мед) и измените его характеристики (выберите объем 0.5л/1л или укажите сорт), после чего нажмите "Добавить в корзину".
4. **Оформление и оплата:** Откройте экран "Корзина", проверьте список товаров и введите адрес доставки. Выберите один из четырех способов оплаты: *Онлайн-оплата, ЕРИП, Терминал* или *Наличные*.
5. **Комментарий и подтверждение:** В специальном текстовом поле оставьте комментарий для курьера (например, детали доставки или бесконтактный метод). Нажмите "Подтвердить заказ". Система сохранит чек в SQLite, очистит корзину и отправит заказ в обработку.
